# Choosing an interaction

Start with the action that would demonstrate the learning goal. Choose a candidate, explain what a response can show, and check that its limits fit the teacher's criterion.

| What the learner does | Candidate | What to check |
|---|---|---|
| Distinguishes plausible interpretations of a figure | MultiChoice | Use distractors tied to different readings. Ask for a separate explanation when the reasoning itself must be assessed. |
| Judges one well-defined claim | TrueFalse | A correct guess is possible. Use feedback or a follow-up when the justification matters. |
| Recalls a term or enters one of a bounded set of answers | Blanks | Test legitimate spellings and number formats. For tolerance, units conversion or algebraic equivalence, look for an evaluator that supports the actual rule. |
| Consults explanations on demand | Accordion | Opening a panel shows access. Add a question if the teacher needs evidence of comprehension. |
| Applies a concept across related questions | QuestionSet | Give each child a purpose and inspect its share of the total score. |
| Classifies, sequences or writes an original explanation | Installed native type or a teacher-reviewed response | Inspect the interaction, scoring and accessible input alternatives before promising that it meets the criterion. |

Use search_h5p_types to check availability and get_h5p_type_contract to inspect the installed version. The authoring adapters identify the supported source versions. If the best candidate requires native authoring, say so. If none of the available interactions collects the required evidence, suggest how the teacher could collect it separately.
