# Designing a screen students can use

Give the learner a reason to look. For a temperature graph, ask which interval warmed faster and what two readings support that choice. Label time, units, axes and intervals beside the data. Verify values and scales against the source. Provide equivalent readings in a compact table or text, preserving the inference for the student. Identify series with labels or shapes as well as color.

Sketch the initial view, the result after a response and the retry state when relevant. Keep the question and its data close enough to compare. After a wrong prediction, point back to the relevant evidence. After a correct one, invite an explanation or transfer. Short labels and a few real values may communicate the task better than an illustration. For an informative Accordion, give each heading a meaningful question and each panel one clear idea.

For scientific figures use verifiable geometry or data and record provenance for assets. Follow the [media rules](media.md) for packaged files. Describe what the image makes available, including values needed to solve the task. If perception itself is assessed, discuss an equivalent task with the teacher.

Inspect the rendered activity at a narrow viewport and with zoom. Try the task by keyboard from start to feedback and retry. Check focus, reading order, labels, legibility, clipped units and whether feedback appears near the decision. Record the player, library version, viewport and states actually exercised.
